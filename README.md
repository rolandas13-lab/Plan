# Arbeitsplan

Statische, zweisprachige GitHub-Pages-Seite für den Arbeitsplan von Jacek und Lukasz. Polnisch ist die Standardsprache, Deutsch ist umschaltbar.

Vorgesehene Adresse:

`https://rolandas13-lab.github.io/Plan/`

## Plan aktualisieren

1. `Planas.xlsx` in diesem Ordner aktualisieren.
2. `tools/generate-data.mjs` ausführen.
3. Die geänderte `schedule-data.js` zu GitHub übertragen.

Das Planende wird aus `Bis!B1` gelesen. Die Feiertags-Schaltflächen zeigen den letzten Ostersonntag und den letzten 25. Dezember.

Die Excel-Datei und das lokale Werkzeug sind durch `.gitignore` von der Veröffentlichung ausgeschlossen.
