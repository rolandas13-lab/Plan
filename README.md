# Arbeitsplan

Statische GitHub-Pages-Seite für den Arbeitsplan von Jacek und Lukasz.

Vorgesehene Adresse:

`https://rolandas13-lab.github.io/Plan/`

## Plan aktualisieren

1. `Planas.xlsx` in diesem Ordner aktualisieren.
2. `tools/generate-data.mjs` ausführen.
3. Die geänderte `schedule-data.js` zu GitHub übertragen.

Die Excel-Datei und das lokale Werkzeug sind durch `.gitignore` von der Veröffentlichung ausgeschlossen.
